# Storyboard: choose a shape, then a hook

There is no single launch-video formula. Pick the story shape that fits the product, the audience and the platform, then a hook type, then the visual style (`motion-cheatsheet.md`). Propose one shape with a reason, mention one alternative, and let the person choose.

## Story shapes

| Shape | Arc | Fits | Watch out for |
|---|---|---|---|
| **A. Problem → product → proof** | A recognisable pain → the product appears → 3–5 feature beats in priority order → a payoff line → end card | B2B and productivity tools with several features | The most common shape; make the hook and payoff specific to this product, not a template line |
| **B. Cold open in the product** | Start inside the UI at its most characteristic moment (an empty input, a notification, a result landing), no voice for the first second or two → widen to what else it does → name and end card | Products people already know or can recognise on sight; social feeds | Needs a screen that is instantly readable |
| **C. One hero flow** | A single job done end to end in 3–5 steps, with the clock or a counter running → result → name | Products with one killer workflow; demos of a new feature | Keep the steps visibly different; don't pad |
| **D. Before / after** | The same task shown the old way and the new way, side by side or as a wipe → what changed → name | Automation, cleanup, redesigns, speed claims | The "before" must be fair; no exaggeration |
| **E. A day with it** | Morning → midday → evening moments where the product shows up → payoff | Consumer and mobile apps, habits, assistants | Needs 3+ distinct, real moments |
| **F. Idea first (explainer)** | One idea or analogy → how the product applies it → one proof → what to try | New categories, technical features, posts about a paper or release | Stay accessible; one idea per screen |
| **G. Teaser** | Fragments and close-ups, the name withheld until the end | Upcoming launches, brand moments | Leaves less room for features |

## Hook types (first 1–3 seconds)

- **Native moment:** the product's own UI doing its most recognisable thing.
- **Specific pain:** a concrete situation the viewer recognises, not a generic question.
- **Bold, true statement or number:** only real, approved numbers.
- **Visual surprise:** an unexpected image or transformation that the rest of the video explains.
- **Sound-led:** a sound the product makes (a notification, a click), then the picture.
- **Direct address:** speaking to a specific viewer ("If you run payroll for a 20-person team…").

Rules: the hook earns the next five seconds; don't open on a logo; vary the hook when making several videos in a row.

## Using reference videos

Study references for craft: pacing, cut rhythm, transitions, camera moves, type treatment, how UI is simplified, how VO lines sit on cuts. **Never copy their content**: hook lines, catchphrases, taglines, scripts, signature openings or exact scene sequences. Before building, compare your script against the reference transcripts and rewrite anything that echoes them. Credit inspiration if you post about the process.

## Shape A as a beat sheet (example timings for 60–75s)

| # | Time | Scene | VO (≈2.5 words/s) | Visual |
|---|---|---|---|---|
| 1 | 0–4s | Hook | One of the hook types above | The situation, shown |
| 2 | 4–9s | Reveal | The product name and a one-line category, in your own words | Logo or name in the brand colour |
| 3 | 9–17s | Feature 1 (most important) | Name concrete things the product does | One real interaction that proves it |
| 4–8 | ~5–12s each | Features 2…n | One benefit per line | One UI moment each; vary the move |
| 9 | ~7s | Crescendo | The most visual feature | The richest screen assembling live |
| 10 | ~3.5s | Payoff | What the viewer gets, specific to this product | Big type in the brand colour |
| 11 | ~5s | End card | Name, tagline (if the product has one), CTA | Logo lockup, CTA + URL |

Other shapes reuse the same building blocks in a different order: B starts at a feature beat, C replaces the feature list with steps, D uses `BeforeAfter`, E uses `Phone` and time-of-day labels.

## Feature-beat recipe (adapt to the chosen style)
1. Optional section label (mono, numbered, or none), entering as the scene starts.
2. Headline: 1–3 short lines, revealed as spoken; at most one emphasised word or phrase, using whatever emphasis fits the style (colour, weight, italic, underline).
3. UI moment: a simplified rebuild of the real screen with the product's real copy and fictional data, and one motion that shows value (a number moving, a card marked done, a notification arriving).
4. Optional cursor: curved path, click feedback, hidden when idle.
5. Exit in the last 0.3s, or let the next scene's entrance cover it.

## Pacing rules
- A new visual event every 1–2s; hold key frames 2–4s; text stays ≥1.5× its reading time.
- Hook in the first 2s.
- Cuts land on beats of the music.
- The end card holds ≥2–3s after the last word.
